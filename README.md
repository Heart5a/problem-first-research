# Problem-First Research

一套从真实问题出发、逐步走向可信方法的实证研究探索流程。

🌐 **博客：** https://heart5a.github.io/problem-first-research/

文章从问题发现开始，经过现象验证、可行性评估、独立复现、机制辨析与方法验证，最后才扩展实验规模。重点是让每一步都有可观察证据、明确判断标准和合理的停止条件。

## 路线

发现问题 → 验证现象 → 评估可行性 → 独立确认 → 梳理研究缺口 → 区分机制 → 设计并验证方法 → 扩大实验

完整文章见 [博客首页](https://heart5a.github.io/problem-first-research/)。
